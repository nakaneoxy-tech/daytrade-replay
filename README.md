# デイトレ練習リプレイ（過去1分足リプレイ型）

過去の日本株1分足を「リアルタイムのように」再生しながら仮想売買を練習するローカルアプリ。
**実際のお金・証券口座とは一切連携しません。**

## 起動

```
cd daytrade-replay
python -m pip install -r requirements.txt   # 初回のみ（flask / yfinance / pandas / anthropic）
python app.py
```

ブラウザで http://localhost:8765 を開く（`start.bat` をダブルクリックでも起動＋ブラウザ表示）。

## 使い方

1. 銘柄コード（例 `6857`、4桁は自動で `6857.T` になる）を入力して **取得**
   - 取得した銘柄は自動で「一括更新リスト」に登録される
   - 日経平均（`^N225`）とドル円（`JPY=X`）も一緒に取得される
2. 練習日を選び、手数料（円/約定）・スリッページ（0〜2ティック）を設定して **この日で開始**
   - 選べるのは実際にデータが取れた日だけ。**当日分は15:30の大引けまで表示されない**
3. 再生／一時停止・速度（0.1〜60倍）・+1分／+10分で進める
4. 買い／売り（空売り可）／全決済。**約定は次の1分足の始値**（寄り前の注文は最初に約定のある足の始値）
5. 15:30 に達すると残ポジションを大引け値で自動決済し、損益と売買履歴を表示。成績はDBに保存され、通算損益・勝率に反映される

### ショートカット
| キー | 動作 |
|---|---|
| Space | 再生／一時停止 |
| → / Shift+→ | +1分 / +10分 |
| B / S | 買い / 売り |
| X / C | 全決済 / 待機注文の取消 |
| 1 / 3 / 5 / F | 1分 / 3分 / 5分 / 15分足 |
| ↑ / ↓ | 株数 ±100 |

## 仕様メモ

- **未来の足は渡さない**：セッションはサーバー側に保持し、進めた分の足だけをブラウザに送る。そのためMA・VWAP・価格帯別出来高・足の集計もすべて現在までのデータだけで計算される（devtoolsでも先が見えない）
- **場時間**：前場 9:00–11:30、後場 12:30–15:30 の分グリッドで再生し、昼休みは飛ばす
- **歯抜けの補完**：取引のなかった分は直前の終値・出来高0の足で埋めるので、時刻軸はずれない。寄り付き前に約定がない分（特別気配など）は前日終値で埋める。補完足では約定させず、次に約定のある足の始値で約定する
- 15:25〜15:30 は東証のクロージング・オークションの時間帯で、yfinance では 15:25 の足に大引けの約定が入る。15:26〜15:30 は補完足になる
- **呼値**：スリッページのティック幅は東証の標準呼値テーブルを使用（TOPIX100構成銘柄のような細かい呼値には未対応）
- **勝率**：建玉がゼロから建ち、ゼロに戻る（またはドテンする）までを1往復として、手数料込みの損益で勝ち負けを数える

## データ更新

- 画面の **データ更新** ボタン：表示中の銘柄と日経平均・ドル円を再取得する
- 一括更新（登録済みの全銘柄＋参考指標）：
  ```
  python update_all.py
  python update_all.py 7203 9984   # 銘柄を追加登録してから一括更新
  ```
- **yfinance の1分足は直近約30日分しか取れない**ので、定期的に実行して練習できる日を貯めていく。取得した足は SQLite（`data/market.db`）に蓄積され、同じ時刻の足は上書きされる
- Windows のタスクスケジューラで平日16:00に自動実行する例：
  ```
  schtasks /Create /TN "DaytradeReplayUpdate" /SC WEEKLY /D MON,TUE,WED,THU,FRI /ST 16:00 /TR "\"C:\path\to\daytrade-replay\update_all.bat\""
  ```
  ログは `data/update.log` に出力される

## データ取得元の差し替え

`dtr/providers/` に `DataProvider`（`fetch_1m(symbol) -> DataFrame`）を実装する。

- `yfinance_provider.py`：初期実装
- `jquants_provider.py`：J-Quants（分足アドオン）用のスタブ。実装したら環境変数 `DATA_PROVIDER=jquants` で切り替える

## AIトレード分析（任意）

- 環境変数 `ANTHROPIC_API_KEY` を設定して起動すると、1日の終了画面に **AIトレード分析** ボタンが出る
- 15分ごとの値動きの要約（VWAP付き）と売買履歴を Claude API（既定 `claude-opus-5`、`DTR_AI_MODEL` で変更可）に送り、良かった判断・改善点・次回のルールをコメントさせる
- **Claude API の従量課金**。ボタンを押したときだけ送信する。キーが未設定なら機能は無効

```
$env:ANTHROPIC_API_KEY = "sk-ant-..."   # PowerShell
python app.py
```

## 動作確認

```
python tests/smoke_test.py
```

6857 を取得 → 1日分を再生 → 寄り前の買い（次の約定足の始値＋スリッページで約定）→ ドテン売り → 15:30 自動決済、までを検証する（`data/smoke.db` を使うので本番の成績には混ざらない）。

## 構成

```
app.py                 Flask サーバー（API＋静的ファイル）
dtr/db.py              SQLite（bars / watchlist / results）
dtr/market.py          場時間グリッド・歯抜け補完・呼値・練習日判定
dtr/engine.py          リプレイ＆仮想売買エンジン（サーバー側でセッションを持つ）
dtr/updater.py         取得・一括更新
dtr/ai.py              Claude API による講評
dtr/providers/         DataProvider（yfinance / J-Quants スタブ）
static/                UI（lightweight-charts）
update_all.py / .bat   一括更新スクリプト
```

## スマホ版（PCを切っていても使える・無料）

サーバーを使わず、GitHub だけで動かす版。`static/` フォルダがそのままサイトになる。

- **データ**：GitHub Actions（`.github/workflows/update-data.yml`）が平日 16:14 に1分足を取得し、`static/data/` に1日ずつファイルで貯める。貯めた日は消えない
- **画面**：GitHub Pages で公開。スマホのブラウザで開き、「ホーム画面に追加」するとアプリのように全画面で使える
- **再生と売買**：スマホのブラウザ内で計算する（`static/local-backend.js`。ルールはPC版の `dtr/engine.py` と同じ）
- **銘柄の追加**：画面の「銘柄を追加（GitHub）」→ Actions の「Run workflow」に銘柄コードを入れて実行。数分後に選べるようになり、以後は毎日自動で更新される
- **PCで手動更新したいとき**：`python export_static.py [銘柄コード…]` を実行して `static/data/` を push

### PC版との違い

| | PC版（`python app.py`） | スマホ版 |
|---|---|---|
| 新しい銘柄 | その場で取得 | 追加してから数分待つ |
| 成績の保存先 | PCの `data/market.db` | その端末のブラウザ内（端末ごとに別。ブラウザのデータを消すと消える） |
| 未来の足 | サーバーから出さない | 画面には出さないが、その日の全データはスマホに届いている |
| AI分析 | 使える（APIキー設定時） | 使えない |

PC版で `static/` を開いても同じ画面が動く（サーバーがあるときは自動でPC版の動作になる）。

### 銘柄名の表示

コードを入れると銘柄名が出る。一覧（`static/data/names.json`）は `update_names.py` が東証（JPX）の上場銘柄一覧から作り、自動更新のたびに作り直す。
